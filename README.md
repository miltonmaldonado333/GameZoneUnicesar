\# GameZone Unicesar



GameZone Unicesar is an information system developed for a video game and console store located in the university sector of Valledupar. This project aims to digitize and automate manual store processes such as inventory control, customer and vendor management, and sales transactions\[cite: 1].



\## Architectural Layers

The project is strictly organized into a four-layer architecture\[cite: 1]:

\* \*\*Model:\*\* Contains domain classes and business entities.

\* \*\*Persistence:\*\* Manages file-based data storage and retrieval.

\* \*\*Service:\*\* Implements core business rules and validation logic.

\* \*\*UI:\*\* Provides a console-based user menu for interaction.



\## Features

\* \*\*Product Management:\*\* Register and list video games and consoles with stock control\[cite: 1].

\* \*\*Person Management:\*\* Register clients and handle preloaded store vendors\[cite: 1].

\* \*\*Sales Registration:\*\* Process transactions, automatically update inventory, and calculate totals\[cite: 1].

\* \*\*Information Queries:\*\* Consult complete histories of sales, client purchases, and vendor transactions\[cite: 1].
